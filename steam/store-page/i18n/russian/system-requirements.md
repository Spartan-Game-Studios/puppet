# Системные требования

## Windows

| | Минимальные | Рекомендуемые |
|---|---|---|
| ОС | Windows 10 64-бит (версия 1809 или новее) | Windows 11 64-бит |
| Процессор | Четырёхъядерный, например Intel Core i5-6500 / AMD Ryzen 3 1300X | Шестиядерный, например Intel Core i5-10400 / AMD Ryzen 5 3600 |
| Оперативная память | 8 ГБ ОЗУ | 16 ГБ ОЗУ |
| Видеокарта | Видеокарта с поддержкой WebGL 2 и актуальными драйверами, например Intel UHD Graphics 620 / NVIDIA GeForce GTX 950 / AMD Radeon RX 460 | NVIDIA GeForce GTX 1060 / AMD Radeon RX 580 или лучше |
| Место на диске | 500 МБ свободного места (плюс ваши аватары и клипы) | 1 ГБ свободного места |
| Дополнительно | **Требуется веб-камера** (720p при 30 fps или лучше). Microsoft Edge WebView2 Runtime (входит в Windows 11). Виртуальная камера: только для 64-битных программ; для её регистрации нужно один раз подтвердить права администратора. Микрофон по желанию (липсинк). | Веб-камера 1080p; ровное фронтальное освещение улучшает трекинг сильнее, чем более дорогая камера. |

## macOS

| | Минимальные | Рекомендуемые |
|---|---|---|
| ОС | macOS 12.3 Monterey | macOS 14 Sonoma или новее |
| Процессор | Apple M1 или четырёхъядерный Intel Core i5 (2018 года или новее) | Apple M1 Pro / M2 или новее |
| Оперативная память | 8 ГБ ОЗУ | 16 ГБ ОЗУ |
| Видеокарта | Встроенная (GPU Apple silicon или Intel Iris Plus) | GPU Apple silicon |
| Место на диске | 500 МБ свободного места (плюс ваши аватары и клипы) | 1 ГБ свободного места |
| Дополнительно | **Требуется веб-камера** (встроенная камера FaceTime подходит). Виртуальная камера устанавливается как расширение камеры, и её нужно один раз разрешить в Системных настройках. Микрофон по желанию (липсинк). | |

## Linux / SteamOS

| | Минимальные | Рекомендуемые |
|---|---|---|
| ОС | 64-битная Ubuntu 22.04 или аналог (WebKitGTK 4.1) | Ubuntu 24.04 или аналог |
| Процессор | Четырёхъядерный, например Intel Core i5-6500 / AMD Ryzen 3 1300X | Шестиядерный, например Intel Core i5-10400 / AMD Ryzen 5 3600 |
| Оперативная память | 8 ГБ ОЗУ | 16 ГБ ОЗУ |
| Видеокарта | Видеокарта с поддержкой WebGL 2 и Mesa 22+ или проприетарным драйвером NVIDIA | NVIDIA GeForce GTX 1060 / AMD Radeon RX 580 или лучше |
| Место на диске | 500 МБ свободного места (плюс ваши аватары и клипы) | 1 ГБ свободного места |
| Дополнительно | **Требуется веб-камера** (V4L2). Для виртуальной камеры нужен модуль ядра v4l2loopback. Общесистемные горячие клавиши работают только в сеансе X11 (в чистом Wayland недоступны). Для прозрачного окна нужен композитор. Микрофон по желанию (липсинк). | |
