# Возможности VPuppet

## Трекинг (обычная веб-камера, Google MediaPipe, всё локально)

- **Лицо:** 52 блендшейпа ARKit (все, кроме `tongueOut`), поворот головы и взгляд.
- **Perfect sync:** модели с выражениями, названными по ARKit, управляются 1:1 по имени (распознаётся при наличии 40+ из 52). Остальные модели получают пресеты VRM, вычисленные из блендшейпов: моргание (обоими глазами и каждым отдельно), пять гласных `aa` `ih` `ou` `ee` `oh` и эмоции happy / angry / sad / surprised / relaxed (отключаемые).
- **Взгляд** управляет look-at модели (через кости или через выражения).
- **Усиление и кривая для каждого блендшейпа** — редактируются вживую рядом с исходным и итоговым значениями.
- **Калибровка** (`C`) запоминает нейтральное выражение лица, положение головы и взгляд.
- **Сглаживание:** один ползунок; моргание и челюсть остаются быстрыми при любом значении.
- **Верх тела:** позвоночник, грудь, плечи, ключицы и руки, с настоящим шарнирным локтем (0–150°), ограниченным скручиванием рук и отдельно ограниченными наклоном и поворотом корпуса.
- **Кисти и пальцы:** каждый сустав пальцев, рассчитанный как анатомические углы и ограниченный их диапазоном; противопоставление большого пальца; кисти отслеживаются в отдельном потоке параллельно с позой; обе руки ищутся по всему кадру в каждом кадре.
- **Жесты:** кулак, открытая ладонь, указательный палец, «мир», большой палец вверх, «окей» и «коза» — для каждой руки, с гистерезисом, чтобы не мерцали.
- **Режимы:** FACE, +BODY, +HANDS; модель позы LITE / FULL, переключается на лету.

## Вывод

- **Виртуальная камера** «VPuppet Virtual Camera» для Zoom, Meet, Discord, FaceTime, OBS и других программ с камерой: 1280×720 или 1920×1080 при 30 fps. Однотонный фон передаётся как хромакей (по умолчанию зелёный); 3D-окружения передаются как есть.
  - macOS 12.3+: расширение камеры CoreMediaIO внутри приложения.
  - Windows 10/11: камера DirectShow (один запрос прав администратора для регистрации).
  - Linux: устройство v4l2loopback.
- **Протокол VMC** через OSC/UDP: все гуманоидные кости, корень, блендшейпы; модели с perfect sync дополнительно отправляют 13 пресетов VRM 0.x, чтобы приёмники, понимающие только пресеты, тоже видели живое лицо. Работает с VSeeFace, Warudo, VNyan, VMC4U и другими приёмниками, локально или по локальной сети.
- **Режим захвата** (`H`): весь интерфейс скрыт для чистого захвата окна в OBS.
- Прозрачный, однотонный (пресеты хромакея) фон или фон-изображение.

## Физика

- **Решатель тканей на костях** поверх собственных spring bones модели VRM: соседние цепочки (кольца юбки, плащи, чёлки) связаны в решётку, чтобы полотна двигались вместе.
- **Коллайдеры тела, построенные по скелету** и подогнанные под меш, в дополнение к собственным коллайдерам модели; непрерывные проверки столкновений по сегментам, чтобы быстрые движения конечностей не проскакивали сквозь ткань.
- Переключатель OFF / STIFF / NORMAL, настройки для каждой цепочки и каждого коллайдера, сохраняются для каждой модели.

## Анимации и управление выступлением

- **Анимационные клипы:** зацикленные idle-анимации (дыхание, осматривание, разговор, скрещённые руки) и эмоуты (кивок, покачивание головой, радость, злость, плач, танец, сесть, попить, помахать, похлопать, указать, пожать плечами, задуматься, поклон) поверх живого трекинга, при этом мимика лица продолжает отслеживаться.
- **Импорт своих** клипов FBX / GLB; риги Mixamo, Unreal-mannequin / UAL и VRoid распознаются по именам костей; ретаргетинг на VRM 0.x и 1.0.
- **Горячие клавиши:** эмоуты и выражения (переключение, включение или удержание) на клавиатуре, геймпаде или жестах рук; необязательные общесистемные клавиши; экранное меню выбора (`G` / RB на геймпаде); привязки для каждой модели.
- **Липсинк с микрофона:** FALLBACK (двигает рот, когда лицо не отслеживается), BLEND или AUDIO; по умолчанию выключен.

## Сцены

- **3D-окружения:** Studio Cyclorama, Cosy Room, Moor at Dusk, Night Clearing, Neon Grid, Concrete Hall (фотостудия, уютная комната, пустошь в сумерках, ночная поляна, неоновая сетка, бетонный зал) — все процедурные (без загрузки ассетов).
- **Свои сцены:** ваш `.glb` / `.gltf` с эквидистантным небом `.hdr` / `.exr` (освещение по изображению, IBL).
- Пресеты света (scene, key, rim, soft), интенсивность, баланс белого, туман, тень на земле, лёгкое покачивание в покое, необязательная глубина резкости; качество LOW / HIGH.
- Кадрирование по грудь / по пояс / в полный рост, масштабируется по размеру аватара.

## Библиотека и приложение

- **Библиотека моделей** на главном экране: миниатюры по грудь, версия VRM, покрытие perfect sync, число треугольников, избранное, поиск, сортировка, переименование; дубликаты отсеиваются, модели копируются в собственную папку приложения.
- **Отображение лицензии:** условия автора каждой VRM-модели показываются простым языком со значком (только автор, только по лицензии, CC0, коммерческое использование разрешено, коммерческое использование только для частных лиц, только личное, без условий). Это информация, а не DRM.
- **Проверки модели:** распространённые ошибки при создании модели отмечаются при загрузке (лицо на затылке, недостающие кости, пустые выражения).
- VRM 0.x и 1.0.
- Навигация с клавиатуры и геймпада везде (`Tab`, режим меню на геймпаде).
- macOS 12.3+, Windows 10/11, Linux.
