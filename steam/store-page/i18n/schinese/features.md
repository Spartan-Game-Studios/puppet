# VPuppet 功能一览

## 追踪（普通摄像头，Google MediaPipe，完全本地运行）

- **面部：**52 个 ARKit BlendShape（除 `tongueOut` 外全部支持）、头部旋转和视线。
- **完美同步（Perfect Sync）：**带有按 ARKit 命名表情的模型会按名称 1:1 驱动（52 个中具备 40 个以上即识别为完美同步模型）。其他模型则会获得由 BlendShape 推算出的 VRM 预设表情：眨眼（双眼及单眼）、五个元音口型 `aa` `ih` `ou` `ee` `oh`，以及喜 / 怒 / 哀 / 惊 / 乐（happy / angry / sad / surprised / relaxed，可关闭）。
- **视线**驱动模型的 LookAt（骨骼型或表情型）。
- **每个 BlendShape 独立的增益和曲线，**可在原始值和输出值旁实时编辑。
- **校准**（`C`）记录你的自然表情、头部角度和视线。
- **平滑：**只需一个滑块；无论如何设置，眨眼和下颌动作都保持灵敏。
- **上半身：**脊柱、胸部、肩膀、锁骨和手臂，肘部为真实的铰链关节（0–150°），手臂扭转有限制，躯干前倾和扭转也分别有限制。
- **双手与手指：**每一个手指关节，按解剖学角度求解并限制在各自范围内；支持拇指对掌；手部在独立线程中与姿态并行追踪；每一帧都在整个画面中搜索双手。
- **手势：**握拳、张开手掌、指向、剪刀手（耶）、竖大拇指、OK 和摇滚手势，左右手分别识别，带迟滞处理防止闪烁。
- **模式：**FACE、+BODY、+HANDS；LITE / FULL 姿态模型，可实时切换。

## 输出

- **虚拟摄像头**“VPuppet Virtual Camera”，适用于 Zoom、Meet、Discord、FaceTime、OBS 及其他摄像头软件：1280×720 或 1920×1080，30 fps。纯色背景以色度键颜色（默认绿幕）输出；3D 场景按渲染画面输出。
  - macOS 12.3+：应用内置的 CoreMediaIO 摄像头扩展。
  - Windows 10/11：DirectShow 摄像头（注册时需一次管理员授权）。
  - Linux：v4l2loopback 设备。
- **VMC 协议**（基于 OSC/UDP）：全部人形骨骼、根节点、BlendShape；完美同步模型还会额外发送 13 个 VRM 0.x 预设表情，让只支持预设的接收端也能看到会动的脸。兼容 VSeeFace、Warudo、VNyan、VMC4U 等接收端，本机或局域网均可。
- **采集视图**（`H`）：隐藏全部界面，方便在 OBS 中干净地进行窗口采集。
- 透明、纯色（色度键预设）或图片背景。

## 物理

- **骨骼布料解算器**，基于 VRM 模型自带的 Spring Bone（摇摆骨）：相邻骨链（裙摆环、披风、刘海）被连接成网格，让布料整片一起运动。
- **根据骨架生成的身体碰撞体**，并贴合模型网格，与模型自带的碰撞体共同工作；采用线段扫掠碰撞检测，快速移动的四肢也不会穿过布料。
- OFF / STIFF / NORMAL 开关，可按骨链和碰撞体单独调整，并按模型保存。

## 动作与表演控制

- **动画片段：**待机循环（呼吸、四处张望、说话、抱臂）和表情动作（点头、摇头、欢呼、生气、哭泣、跳舞、坐下、喝水、挥手、鼓掌、指向、耸肩、思考、鞠躬），叠加在实时追踪之上，期间面部表情仍持续追踪。
- **导入自己的** FBX / GLB 动画片段；根据骨骼名称识别 Mixamo、Unreal 小白人（Mannequin）/ UAL 和 VRoid 骨架；重定向到 VRM 0.x 和 1.0 模型。
- **快捷键：**表情动作和表情（切换、开启或按住）可绑定到键盘、手柄或手势；可选全局热键；屏幕选择面板（`G` / 手柄 RB）；按模型保存绑定。
- **麦克风口型同步：**FALLBACK（面部未被追踪时驱动嘴部）、BLEND 或 AUDIO；默认关闭。

## 场景

- **3D 场景：**Studio Cyclorama、Cosy Room、Moor at Dusk、Night Clearing、Neon Grid、Concrete Hall（摄影棚、温馨小屋、黄昏荒原、夜间林地、霓虹网格、混凝土大厅），全部为程序化生成（无需下载素材）。
- **自定义场景：**你自己的 `.glb` / `.gltf`，搭配等距柱状投影的 `.hdr` / `.exr` 天空（基于图像的光照）。
- 灯光预设（scene、key、rim、soft）、强度、白平衡、雾效、地面阴影、待机摇摆、可选景深；LOW / HIGH 画质。
- 胸像 / 半身 / 全身取景，随模型大小自动缩放。

## 模型库与应用

- **模型库**主界面：胸像缩略图、VRM 版本、完美同步覆盖率、三角面数、收藏、搜索、排序、重命名；模型自动去重并复制到应用自己的文件夹中。
- **使用条款显示：**每个 VRM 的作者条款都会以通俗语言配合标识显示（仅作者、仅授权者、CC0、允许商用、个人商用、个人使用、无条款）。仅供参考，并非 DRM。
- **模型检查：**加载时标出常见的制作问题（脸长在后脑勺、缺失骨骼、空表情）。
- VRM 0.x 和 1.0。
- 全程支持键盘和手柄导航（`Tab`、手柄菜单模式）。
- macOS 12.3+、Windows 10/11、Linux。
