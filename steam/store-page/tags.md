# Suggested Steam tags

Steam allows up to 20 tags; the order matters (the top tags weigh most in recommendations and show first on the capsule). Enter them in Store page → Tags in this order.

Steam's tag list is fixed; you can only pick existing tags. **Check each one exists in the Steamworks tag picker before relying on this list.** Some obvious words (e.g. "VTuber") are not tags on Steam at the time of writing; if Valve has added one by launch, put it at #1.

| Rank | Tag | Why |
|---|---|---|
| 1 | Video Production | The closest software category: it makes a camera feed for streams and calls. |
| 2 | Animation & Modeling | Live avatar animation, clip retargeting. |
| 3 | Utilities | Virtual camera, VMC output, works alongside other apps. |
| 4 | Software | Marks it as an application, not a game. |
| 5 | Anime | Most VRM avatars (VRoid and others) are anime-styled; this is where the audience browses. |
| 6 | 3D | Real-time 3D avatar and environments. |
| 7 | Design & Illustration | Creators who build their own avatar look here. |
| 8 | Character Customization | Bring-your-own avatar, per-shape tuning. |
| 9 | Stylized | Matches the art style of typical VRM avatars. |
| 10 | Cute | Same audience; widely followed tag. |
| 11 | Controller | Full gamepad navigation and gamepad emote hotkeys. |
| 12 | Indie | Small studio. |
| 13 | Colorful | The built-in scenes (neon grid, dusk). |
| 14 | Simulation | Physics-driven cloth and hair (use only if the picker offers nothing more specific). |
| 15 | Sandbox | Free-form use of your own models, scenes and clips. |
| 16 | Moddable | Custom avatars, animation clips, scenes and skies from your own files. Drop it if Valve reads it as "has mod tooling". |
| 17 | Photo Editing | Weak fit; only if more reach is wanted. Probably leave out. |

Leave these out: Free to Play (it isn't; the demo is separate), Early Access (unless it launches as EA), VR (it doesn't use a headset; "VRM" is a file format, not VR), Multiplayer/Co-op, anything about gameplay genres.

## Steam categories (separate from tags)

- Partial Controller Support (not Full: file dialogs and OS permission prompts aren't controller-driven).
- No Steam Achievements, Cloud, Trading Cards or Workshop at launch.
- Includes level editor: no.
