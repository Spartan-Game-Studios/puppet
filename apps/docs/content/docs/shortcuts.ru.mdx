---
title: Горячие клавиши
description: Все клавиши и кнопки геймпада в одном месте.
---

`Tab` позволяет добраться до любого элемента управления в приложении. На геймпаде `LT` включает режим меню на сцене.

## Сцена

| Клавиша | Действие |
|---|---|
| `L` / `Esc` | Назад на HOME (библиотека моделей) |
| `I` | MODEL INFO и лицензия |
| `O` | Открыть `.vrm` |
| `C` | Калибровка нейтрального положения |
| `1` `2` `3` | Режим трекинга: FACE / +BODY / +HANDS |
| `M` | Зеркалирование |
| `T` | Свернуть / развернуть карточку камеры |
| `E` | 3D-окружение вкл. / выкл. |
| `H` | Режим захвата |
| `Esc` | Выйти из режима захвата |
| `W` | Виртуальная камера вкл. / выкл. |
| `V` | Вывод VMC вкл. / выкл. |
| `8` `9` `0` | Физика OFF / STIFF / NORMAL |
| `R` | Успокоить физику |
| `D` | Отладочный оверлей |
| `G` | Меню выбора эмоций и выражений (picker) |

## Окна настроек

Каждая клавиша открывает своё окно; та же клавиша или `Esc` закрывает его.

| Клавиша | Окно |
|---|---|
| `B` | SCENE: фон и 3D-окружение |
| `F` | FACE: усиление и кривые блендшейпов |
| `P` | PHYSICS |
| `A` | MOTION |
| `K` | HOTKEYS |
| `S` | LIP SYNC |
| `N` | VMC |

## HOME (библиотека моделей)

| Клавиша | Действие |
|---|---|
| `←` `↑` `↓` `→` | Перемещение |
| `Enter` | Загрузить |
| `S` | В избранное |
| `L` | Лицензия |
| `F2` | Переименовать |
| `Del` | Удалить из библиотеки |
| `/` | Поиск |
| `I` | Импорт |
| `Esc` | Назад на сцену |

## Горячие клавиши по умолчанию

Меняются в **HOTKEYS** (`K`).

| Клавиша | Действие |
|---|---|
| `⌥1` `⌥2` `⌥3` `⌥4` `⌥5` | happy / angry / sad / relaxed / surprised |
| `⌥6` | Сброс |
| `F3` | Wave |
| `F4` | Nod |
| `F5` | Shake |
| `F6` | Clap |
| `F7` | Cheer |
| `F8` | Bow |
| `F9` | Shrug |
| `F10` | Think |
| `G` | Picker |

`⌥` — это Option на macOS и Alt на Windows и Linux.

## Геймпад (стандартная раскладка)

| Кнопка | Действие |
|---|---|
| `A` | Wave |
| `B` | Nod |
| `X` | Clap |
| `Y` | Cheer |
| крестовина | happy / surprised / sad / angry |
| `LB` | Shrug |
| `RB` | Picker |
| `BACK` | Сброс |
| `LT` | Режим меню (сцена) |

В режиме меню, в окнах настроек и на HOME: крестовина или левый стик перемещают, `A` нажимает, влево / вправо меняют ползунки и выпадающие списки, `B` — назад или закрыть.
