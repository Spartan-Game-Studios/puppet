---
title: Липсинк
description: Управляйте ртом с микрофона, когда камера его не видит, или вместе с трекингом.
---

Откройте **LIP SYNC** (`S`). По умолчанию липсинк выключен; VPuppet запрашивает доступ к микрофону только когда вы выбираете режим.

## Режимы

![Окно ЛИПСИНК: режим, микрофон, порог, усиление и уровни визем](/screenshots/ru/lipsync.webp)

| Режим | Что управляет ртом |
|---|---|
| **OFF** | Только трекинг лица. |
| **FALLBACK** | Ваш голос, но только пока лицо не отслеживается (с плавным переходом). |
| **BLEND** | Большее из значений трекинга и голоса, для каждой формы отдельно. |
| **AUDIO** | Только голос. |

## Настройки

- Выберите **микрофон**.
- **GATE DB** задаёт уровень, ниже которого звук игнорируется. Увеличьте его, если фоновый шум двигает рот.
- Индикатор показывает уровень входного сигнала, порог и каждую распознанную форму рта.

VPuppet сопоставляет ваш голос с пятью гласными. Модели с пресетами получают `aa` `ih` `ou` `ee` `oh`; модели perfect sync — `jawOpen`, `mouthFunnel`, `mouthPucker` и `mouthStretch`. Рот открывается быстро (30 мс) и закрывается чуть медленнее (90 мс).

<Callout title="FALLBACK и слабый трекинг">
FALLBACK переключается только при потере лица. Он не может определить, что трекинг рта просто слабый; для этого используйте BLEND.
</Callout>
