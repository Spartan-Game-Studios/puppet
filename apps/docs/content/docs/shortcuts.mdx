---
title: Keyboard shortcuts
description: Every key and gamepad button in one place.
---

`Tab` reaches every control in the app. On a gamepad, `LT` enters menu mode on the stage.

## Stage

| Key | Action |
|---|---|
| `L` / `Esc` | Back to HOME (the model library) |
| `I` | MODEL INFO and licence |
| `O` | Open a `.vrm` |
| `C` | Calibrate neutral |
| `1` `2` `3` | Tracking mode: FACE / +BODY / +HANDS |
| `M` | Mirror |
| `T` | Minimise / restore the camera card |
| `E` | 3D environment on / off |
| `H` | Capture view |
| `Esc` | Leave capture view |
| `W` | Virtual camera on / off |
| `V` | VMC output on / off |
| `8` `9` `0` | Physics OFF / STIFF / NORMAL |
| `R` | Settle physics |
| `D` | Debug overlay |
| `G` | Emote and expression picker |

## Settings windows

Each key opens its window; the same key or `Esc` closes it.

| Key | Window |
|---|---|
| `B` | SCENE: background and 3D environment |
| `F` | FACE: blendshape gains and curves |
| `P` | PHYSICS |
| `A` | MOTION |
| `K` | HOTKEYS |
| `S` | LIP SYNC |
| `N` | VMC |

## HOME (model library)

| Key | Action |
|---|---|
| `←` `↑` `↓` `→` | Move |
| `Enter` | Load |
| `S` | Favourite |
| `L` | Licence |
| `F2` | Rename |
| `Del` | Remove from library |
| `/` | Search |
| `I` | Import |
| `Esc` | Back to the stage |

## Default hotkeys

Editable in **HOTKEYS** (`K`).

| Key | Action |
|---|---|
| `⌥1` `⌥2` `⌥3` `⌥4` `⌥5` | happy / angry / sad / relaxed / surprised |
| `⌥6` | Reset |
| `F3` | Wave |
| `F4` | Nod |
| `F5` | Shake |
| `F6` | Clap |
| `F7` | Cheer |
| `F8` | Bow |
| `F9` | Shrug |
| `F10` | Think |
| `G` | Picker |

`⌥` is Option on macOS and Alt on Windows and Linux.

## Gamepad (standard mapping)

| Button | Action |
|---|---|
| `A` | Wave |
| `B` | Nod |
| `X` | Clap |
| `Y` | Cheer |
| d-pad | happy / surprised / sad / angry |
| `LB` | Shrug |
| `RB` | Picker |
| `BACK` | Reset |
| `LT` | Menu mode (stage) |

In menu mode, settings windows and HOME: d-pad or left stick moves, `A` presses, left / right change sliders and drop-downs, `B` backs out or closes.
