---
title: 键盘快捷键
description: 所有按键和手柄按钮汇总在一处。
---

`Tab` 可以到达应用中的每个控件。使用手柄时，在舞台上按 `LT` 进入菜单模式。

## 舞台

| 按键 | 操作 |
|---|---|
| `L` / `Esc` | 返回 HOME（模型库） |
| `I` | MODEL INFO 和许可 |
| `O` | 打开 `.vrm` |
| `C` | 校准中性表情 |
| `1` `2` `3` | 追踪模式：FACE / +BODY / +HANDS |
| `M` | 镜像 |
| `T` | 最小化 / 恢复摄像头卡片 |
| `E` | 开关 3D 环境 |
| `H` | 捕获视图 |
| `Esc` | 退出捕获视图 |
| `W` | 开关虚拟摄像头 |
| `V` | 开关 VMC 输出 |
| `8` `9` `0` | 物理 OFF / STIFF / NORMAL |
| `R` | 物理归位 |
| `D` | 调试叠加层 |
| `G` | 表情动作与表情选择器 |

## 设置窗口

每个按键打开对应窗口；按同一个键或 `Esc` 关闭。

| 按键 | 窗口 |
|---|---|
| `B` | SCENE：背景和 3D 环境 |
| `F` | FACE：混合形状增益和曲线 |
| `P` | PHYSICS |
| `A` | MOTION |
| `K` | HOTKEYS |
| `S` | LIP SYNC |
| `N` | VMC |

## HOME（模型库）

| 按键 | 操作 |
|---|---|
| `←` `↑` `↓` `→` | 移动 |
| `Enter` | 加载 |
| `S` | 收藏 |
| `L` | 许可 |
| `F2` | 重命名 |
| `Del` | 从库中移除 |
| `/` | 搜索 |
| `I` | 导入 |
| `Esc` | 返回舞台 |

## 默认快捷键

可在 **HOTKEYS**（`K`）中编辑。

| 按键 | 操作 |
|---|---|
| `⌥1` `⌥2` `⌥3` `⌥4` `⌥5` | happy / angry / sad / relaxed / surprised |
| `⌥6` | 重置 |
| `F3` | 挥手 |
| `F4` | 点头 |
| `F5` | 摇头 |
| `F6` | 鼓掌 |
| `F7` | 欢呼 |
| `F8` | 鞠躬 |
| `F9` | 耸肩 |
| `F10` | 思考 |
| `G` | 选择器 |

`⌥` 在 macOS 上是 Option 键，在 Windows 和 Linux 上是 Alt 键。

## 手柄（标准映射）

| 按钮 | 操作 |
|---|---|
| `A` | 挥手 |
| `B` | 点头 |
| `X` | 鼓掌 |
| `Y` | 欢呼 |
| 十字键 | happy / surprised / sad / angry |
| `LB` | 耸肩 |
| `RB` | 选择器 |
| `BACK` | 重置 |
| `LT` | 菜单模式（舞台） |

在菜单模式、设置窗口和 HOME 中：十字键或左摇杆移动，`A` 按下，左 / 右调整滑块和下拉菜单，`B` 返回或关闭。
