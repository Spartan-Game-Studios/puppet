## 首次启动

VPuppet 启动后进入 **HOME**，即模型库。首次启动摄像头时，操作系统会请求摄像头权限：请允许。如果你关闭了该提示，请参见[摄像头权限](./faq.mdx#camera-doesnt-start)。

## 导入模型

在 HOME 上点击 **IMPORT .VRM**（导入 .VRM，`I`），或把一个或多个 `.vrm` 文件拖到窗口上。每个文件都会显示导入进度；不是 VRM 的文件会在自己的卡片上提示。

你也可以在舞台上用 **OPEN**（`O`）打开模型，或把 `.vrm` 拖到窗口上。无论哪种方式，模型都会加入模型库，之后可以从 HOME 重新打开。VPuppet 会保存自己的副本，因此之后移动或删除原文件都没有问题。

在 HOME 上选中模型并按 `Enter`（或点击它），即可将其加载到舞台上。

<Callout title="许可">
每个 VRM 都带有作者的使用条款。VPuppet 会在卡片的徽章和 **MODEL INFO**（模型信息，舞台上按 `I`）中显示这些条款。参见[模型库](./model-library.mdx#licence-badges)。
</Callout>

## 舞台

视口占据大部分空间。四周分别是：

- **顶栏：** HOME、OPEN，以及每个设置窗口各一个按钮：**SCENE**（`B`）、**FACE**（`F`）、**PHYSICS**（`P`）、**MOTION**（`A`）、**HOTKEYS**（`K`）、**LIP SYNC**（`S`）和 **VMC**（`N`）。每个窗口都停靠在右侧，让模型始终可见。按同一个键或 `Esc` 关闭。
- **左栏：** **01 TRACKING**（模式、姿态模型、平滑、视线增益、情绪、CALIBRATE）和 **02 FRAMING**（BUST / UPPER / FULL 取景）。
- **摄像头卡片**（左下角）：带关键点叠加的摄像头预览、**SOURCE** 区（摄像头、分辨率、追踪帧率、镜像、重启）以及 **VIRTUAL CAM** 区。`T` 可将其折叠为一条窄栏；追踪会继续运行。
- **底栏：** 模型名称及其许可徽章（点击或按 `I` 打开 MODEL INFO）、追踪状态（TRACKING / LOST / FACE ONLY）、当前表情动作或表情、PERFECT SYNC 或 PRESETS、已开启的输出（VMC、VCAM）以及状态行。
- **调试叠加层**（`D`）：渲染和追踪帧率、延迟、手势以及手部搜索状态。

按 `L` 或 `Esc` 返回 HOME。

## 校准 [#calibrate]

以平时的姿势坐好，看着屏幕，睁开眼睛、闭上嘴，然后按 **CALIBRATE**（校准，`C`）。VPuppet 会把此时的中性表情、头部角度和视线记为零点。**CLR** 清除校准。

在你校准之前，VPuppet 会自动把第一秒稳定的睁眼闭嘴状态当作中性（不会保存）。尽管如此，自己校准仍然值得，尤其是摄像头放在一侧时。

## 追踪模式

| 按键 | 模式 | 追踪内容 |
|---|---|---|
| `1` | **FACE** | 面部、头部和视线。身体播放待机片段。 |
| `2` | **+BODY** | 增加脊柱、胸部、肩膀和手臂。 |
| `3` | **+HANDS** | 增加每根手指和手势。 |

模式越高，占用的计算资源越多。先从 FACE 开始，一切运行流畅后再逐级提高。腿部始终不追踪。

## 镜像

`M` 镜像摄像头画面，这样你举起右手时，模型会在屏幕同一侧举手。
