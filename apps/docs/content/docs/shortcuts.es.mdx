---
title: Atajos de teclado
description: Todas las teclas y los botones del mando en un solo lugar.
---

`Tab` llega a todos los controles de la app. Con un mando, `LT` activa el modo menú en el escenario.

## Escenario

| Tecla | Acción |
|---|---|
| `L` / `Esc` | Volver a HOME (la biblioteca de modelos) |
| `I` | MODEL INFO y licencia |
| `O` | Abrir un `.vrm` |
| `C` | Calibrar la posición neutra |
| `1` `2` `3` | Modo de seguimiento: FACE / +BODY / +HANDS |
| `M` | Espejo |
| `T` | Minimizar / restaurar la tarjeta de la cámara |
| `E` | Entorno 3D activado / desactivado |
| `H` | Vista de captura |
| `Esc` | Salir de la vista de captura |
| `W` | Cámara virtual activada / desactivada |
| `V` | Salida VMC activada / desactivada |
| `8` `9` `0` | Física OFF / STIFF / NORMAL |
| `R` | Asentar la física |
| `D` | Superposición de depuración |
| `G` | Selector de emotes y expresiones |

## Ventanas de ajustes

Cada tecla abre su ventana; la misma tecla o `Esc` la cierra.

| Tecla | Ventana |
|---|---|
| `B` | SCENE: fondo y entorno 3D |
| `F` | FACE: ganancias y curvas de los blendshapes |
| `P` | PHYSICS |
| `A` | MOTION |
| `K` | HOTKEYS |
| `S` | LIP SYNC |
| `N` | VMC |

## HOME (biblioteca de modelos)

| Tecla | Acción |
|---|---|
| `←` `↑` `↓` `→` | Moverse |
| `Enter` | Cargar |
| `S` | Favorito |
| `L` | Licencia |
| `F2` | Renombrar |
| `Del` | Quitar de la biblioteca |
| `/` | Buscar |
| `I` | Importar |
| `Esc` | Volver al escenario |

## Atajos por defecto

Se pueden editar en **HOTKEYS** (`K`).

| Tecla | Acción |
|---|---|
| `⌥1` `⌥2` `⌥3` `⌥4` `⌥5` | happy / angry / sad / relaxed / surprised |
| `⌥6` | Restablecer |
| `F3` | Wave (saludar) |
| `F4` | Nod (asentir) |
| `F5` | Shake (negar) |
| `F6` | Clap (aplaudir) |
| `F7` | Cheer (celebrar) |
| `F8` | Bow (reverencia) |
| `F9` | Shrug (encogerse de hombros) |
| `F10` | Think (pensar) |
| `G` | Selector |

`⌥` es Opción en macOS y Alt en Windows y Linux.

## Mando (asignación estándar)

| Botón | Acción |
|---|---|
| `A` | Wave |
| `B` | Nod |
| `X` | Clap |
| `Y` | Cheer |
| cruceta | happy / surprised / sad / angry |
| `LB` | Shrug |
| `RB` | Selector |
| `BACK` | Restablecer |
| `LT` | Modo menú (escenario) |

En el modo menú, en las ventanas de ajustes y en HOME: la cruceta o el stick izquierdo mueven, `A` pulsa, izquierda / derecha cambian los deslizadores y los desplegables, `B` vuelve atrás o cierra.
