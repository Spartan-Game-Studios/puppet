## Клипы (MOTION, `A`)

В окне **MOTION** находятся idle-цикл и эмоции. Они проигрываются поверх живого трекинга.

### Встроенные клипы

| Клип | Что двигает по умолчанию |
|---|---|
| IDLE: BREATHE / LOOK AROUND / TALKING / ARMS FOLDED | всё тело (idle) |
| NOD (YES), SHAKE (NO) | голова |
| CHEER, ANGRY, CRY | тело |
| DANCE, SIT (повторяются, пока не запустить снова) | всё тело |
| DRINK | руки |
| WAVE, CLAP, POINT | руки |
| SHRUG, THINK | тело |
| BOW | всё тело |

Большинство клипов взято из [Quaternius Universal Animation Library](https://quaternius.com) (CC0). WAVE, CLAP, POINT, SHRUG, THINK и BOW — простые позы на ключевых кадрах, сделанные для VPuppet, а не захват движения.

### Как клипы сочетаются с трекингом

- **Idle**-клип проигрывается, пока трекинг тела выключен (режим FACE) или потерян. Пока лицо отслеживается, голова остаётся вашей.
- **Эмоция** проигрывается поверх живого трекинга и забирает только нужные ей кости (всё тело, тело без головы, руки или голову), плавно появляясь и исчезая. Выражения лица отслеживаются во время любой эмоции.
- Клипы, которые двигают бёдра (например, SIT), переходят медленнее, чтобы ткань успевала следовать.

### Ваши клипы

Нажмите **IMPORT CLIP** или перетащите `.fbx` или `.glb` в окно. (Файл `.glb` без анимаций воспринимается как 3D-сцена.)

- Риги Mixamo, Quaternius UAL / манекена Unreal и VRoid распознаются по именам костей; распространённые имена из Blender и Unity тоже работают.
- Клипы переносятся (ретаргетинг) на любой VRM (0.x и 1.0). Перемещение в пространстве убирается, чтобы аватар оставался на месте; покачивание и высота посадки сохраняются.
- Каждая анимация в файле становится отдельной записью. VPuppet хранит копию, как и в библиотеке моделей.

<Callout type="warn" title="Ограничения ретаргетинга">
Ретаргетинг копирует направления костей, а не касания: на модели с сильно отличающимися пропорциями руки, которые должны касаться лица или друг друга, могут промахнуться. Импорт клипов из `.gltf` с отдельными файлами не поддерживается; используйте `.glb` или `.fbx`. Условия Mixamo не разрешают распространять их файлы, поэтому импортируйте собственные загрузки.
</Callout>

## Горячие клавиши (HOTKEYS, `K`) [#hotkeys]

Каждая привязка сопоставляет **триггер** с **действием**.

- **Триггеры:** клавиша или сочетание клавиш, кнопка геймпада или жест руки.
- **Действия:** проиграть эмоцию; задать выражение (**TOGGLE** — переключить, **ON** — включить или **HOLD** — пока нажато; любой пресет VRM или собственное выражение модели, с плавными переходами); **RESET**; или открыть **PICKER**.

Щёлкните по триггеру, чтобы переназначить его. Точка отмечает привязку, которая относится только к текущей модели (выражения у моделей разные); собственная привязка модели перекрывает глобальную на том же триггере. Конфликты с другой привязкой или с клавишей приложения обводятся рамкой.

### Привязки по умолчанию

| Триггер | Действие |
|---|---|
| `⌥1` – `⌥5` (Alt+1 – Alt+5) | happy / angry / sad / relaxed / surprised |
| `⌥6` | сброс выражений |
| `F3` `F4` `F5` `F6` | wave, nod, shake, clap |
| `F7` `F8` `F9` `F10` | cheer, bow, shrug, think |
| `G` | picker |

Клавиши выражений используют Alt, потому что `1` `2` `3` — режимы трекинга.

### Геймпад

Геймпады со стандартной раскладкой поддерживаются полноценно:

| Кнопка | Действие |
|---|---|
| `A` | wave |
| `B` | nod |
| `X` | clap |
| `Y` | cheer |
| крестовина | happy / surprised / sad / angry |
| `LB` | shrug |
| `RB` | picker |
| `BACK` | сброс |

Кнопки геймпада работают всё время, пока VPuppet запущен, даже в фоне.

**Режим меню:** на сцене `LT` включает режим меню: крестовина или стик перемещают фокус, `A` нажимает, влево / вправо меняют ползунки и выпадающие списки, `B` — назад. Окна настроек и HOME сами принимают управление с геймпада. Вне их геймпад остаётся в вашем распоряжении для выступления.

### Жесты рук

В режиме +HANDS семь отслеживаемых жестов (кулак, открытая ладонь, указательный палец, «мир», большой палец вверх, OK, «коза») можно использовать как триггеры, отдельно для каждой руки.

### Глобальные горячие клавиши

**GLOBAL** (по умолчанию выключено) регистрирует ваши клавиатурные привязки во всей системе, так что они работают, когда в фокусе OBS или игра.

- Глобально зарегистрированная клавиша отнимается у всех остальных программ, пока работает VPuppet, поэтому лучше используйте сочетания.
- Сочетание, которое уже занято другой программой, не регистрируется; оно отображается в списке и по-прежнему работает внутри VPuppet.
- На macOS разрешение «Универсальный доступ» не требуется. На Linux глобальным клавишам нужен сеанс X11; в чистом Wayland они недоступны. Пока глобальные клавиши проверены только на macOS.

### Picker

`G` или `RB` на геймпаде открывает поверх сцены сетку эмоций и выражений. Стрелки / крестовина / левый стик — перемещение, `Enter` / `A` — запуск, `Esc` / `B` — закрыть.
