## 动画片段（MOTION，`A`）

![动作窗口：待机循环、表情动作及其遮罩](/screenshots/zh-CN/motion.webp)

**MOTION** 窗口包含待机循环和表情动作。它们叠加在实时追踪之上播放。

### 内置片段

| 片段 | 默认驱动部位 |
|---|---|
| IDLE: BREATHE / LOOK AROUND / TALKING / ARMS FOLDED | 全身（待机） |
| NOD (YES), SHAKE (NO) | 头部 |
| CHEER, ANGRY, CRY | 身体 |
| DANCE, SIT（循环，直到再次触发） | 全身 |
| DRINK | 手臂 |
| WAVE, CLAP, POINT | 手臂 |
| SHRUG, THINK | 身体 |
| BOW | 全身 |

大多数片段来自 [Quaternius Universal Animation Library](https://quaternius.com)（CC0）。WAVE、CLAP、POINT、SHRUG、THINK 和 BOW 是为 VPuppet 制作的简单关键帧姿势，不是动作捕捉。

### 片段如何与追踪混合

- **待机**片段在身体追踪关闭（FACE 模式）或丢失时播放。面部被追踪时，头部仍由你控制。
- **表情动作**叠加在实时追踪之上播放，只接管它需要的骨骼（全身、不含头部的身体、手臂或头部），并淡入淡出。所有表情动作期间，面部表情仍保持追踪。
- 会移动臀部的片段（如 SIT）淡入淡出更慢，让布料跟得上。

### 你自己的片段

点击 **IMPORT CLIP**（导入片段），或把 `.fbx` 或 `.glb` 拖到窗口上。（不含动画的 `.glb` 会被当作 3D 场景。）

- Mixamo、Quaternius UAL / Unreal 人体模型和 VRoid 的绑定可通过骨骼名称识别；常见的 Blender 和 Unity 命名也可以。
- 片段会重定向到任意 VRM（0.x 和 1.0）。位移会被去除，让模型留在原地；上下起伏和坐下的高度会保留。
- 文件中的每个动画都会成为单独的条目。VPuppet 会保存一份副本，与模型库相同。

<Callout type="warn" title="重定向的局限">
重定向复制的是骨骼方向，而不是接触关系：在比例差异很大的模型上，本应碰到脸或彼此相碰的手可能会错开。动画片段不支持带有独立文件的 `.gltf`；请使用 `.glb` 或 `.fbx`。Mixamo 的条款不允许再分发其文件，请导入你自己下载的文件。
</Callout>

## 快捷键（HOTKEYS，`K`） [#hotkeys]

![快捷键窗口：键盘和手柄绑定](/screenshots/zh-CN/hotkeys.webp)

每个绑定把一个**触发器**映射到一个**操作**。

- **触发器：** 一个按键或组合键、一个手柄按钮，或一个手势。
- **操作：** 播放表情动作；设置表情（**TOGGLE** 切换、**ON** 开启，或 **HOLD** 按住时生效；可用模型上的任何 VRM 预设或自定义表情，带淡入淡出）；**RESET**（重置）；或打开 **PICKER**（选择器）。

点击触发器即可重新绑定。圆点表示该绑定只属于当前模型（不同模型的表情不同）；同一触发器上，模型自己的绑定优先于全局绑定。与其他绑定或应用快捷键冲突时会加上轮廓提示。

### 默认绑定

| 触发器 | 操作 |
|---|---|
| `⌥1` – `⌥5`（Alt+1 – Alt+5） | happy / angry / sad / relaxed / surprised |
| `⌥6` | 重置表情 |
| `F3` `F4` `F5` `F6` | 挥手、点头、摇头、鼓掌 |
| `F7` `F8` `F9` `F10` | 欢呼、鞠躬、耸肩、思考 |
| `G` | 选择器 |

表情键使用 Alt，因为 `1` `2` `3` 是追踪模式。

### 手柄

使用标准映射的手柄得到完整支持：

| 按钮 | 操作 |
|---|---|
| `A` | 挥手 |
| `B` | 点头 |
| `X` | 鼓掌 |
| `Y` | 欢呼 |
| 十字键 | happy / surprised / sad / angry |
| `LB` | 耸肩 |
| `RB` | 选择器 |
| `BACK` | 重置 |

只要 VPuppet 在运行，手柄按钮就能使用，即使它在后台。

**菜单模式：** 在舞台上按 `LT` 进入菜单模式：十字键或摇杆移动焦点，`A` 按下，左 / 右调整滑块和下拉菜单，`B` 返回。设置窗口和 HOME 会自动接管手柄。除此之外，手柄保留给你用于表演。

### 手势

在 +HANDS 模式下，七种可追踪的手势（握拳、张开手掌、指向、剪刀手、竖大拇指、OK、摇滚手势）可以按每只手分别作为触发器。

### 全局快捷键

**GLOBAL**（默认关闭）会在系统范围内注册你的键盘绑定，因此在 OBS 或游戏处于焦点时也能使用。

- 全局注册的按键在 VPuppet 运行期间会被所有其他应用让出，因此建议使用组合键。
- 已被其他应用占用的组合键无法注册；它会被列出，并且在 VPuppet 内仍然可用。
- macOS 上不需要辅助功能权限。Linux 上全局快捷键需要 X11 会话；纯 Wayland 下不可用。目前全局快捷键仅在 macOS 上测试过。

### 选择器

按 `G` 或手柄 `RB` 会在舞台上打开表情动作和表情的网格。方向键 / 十字键 / 左摇杆移动，`Enter` / `A` 触发，`Esc` / `B` 关闭。
