title: Виртуальная камера

VPuppet может отображаться как веб-камера под названием **VPuppet Virtual Camera**, чтобы программы видеосвязи и стриминга могли использовать аватар напрямую. Управление находится в разделе **VIRTUAL CAM** карточки камеры, внизу слева на сцене. `W` включает и выключает вывод.

## Что передаёт камера

- **Режим захвата**: аватар без интерфейса, с тем же кадрированием, светом и сценой, что и на экране.
- **1280×720** (по умолчанию) или **1920×1080**, **30 кадров/с**.
- Камеры не передают прозрачность. При фоне **CLEAR** аватар отправляется поверх выбранного цвета (по умолчанию зелёный `#00ff00`), так что его можно вырезать хромакеем. 3D-окружение передаётся как есть, кроме глубины резкости, которая видна только на экране.

## Однократная настройка [#setup]

Панель подскажет, чего ещё не хватает вашей системе, и предложит нужную кнопку.

<Tabs items={['macOS', 'Windows', 'Linux']}>
<Tab value="macOS">

Нужна macOS 12.3 или новее и подписанная сборка (сборка из Steam подписана).

<Steps>
<Step>
Переместите **VPuppet.app** в **/Applications** и запускайте оттуда. macOS устанавливает расширения камеры только из приложений в /Applications.
</Step>
<Step>
В разделе **VIRTUAL CAM** нажмите **INSTALL** в строке **EXTENSION**.
</Step>
<Step>
Одобрите установку. Нажмите **OPEN SETTINGS** на панели, чтобы перейти на нужную страницу:

- macOS 15 и новее: **Системные настройки → Основные → Объекты входа и расширения → Расширения камеры** и включите **VPuppet**.
- macOS 13–14: **Системные настройки → Конфиденциальность и безопасность** и нажмите **Разрешить** под сообщением о системном ПО VPuppet.
</Step>
<Step>
В строке EXTENSION появится **ACTIVE**. Включите **CAMERA OUTPUT** (`W`).
</Step>
</Steps>

Камера существует только пока VPuppet передаёт изображение. Выключите вывод или закройте VPuppet — и **VPuppet Virtual Camera** исчезнет из списка камер во всех программах, так что зависшей или чёрной камеры не останется. Если программа показывает **VPUPPET / WAITING FOR FRAMES**, камера есть, но кадры ещё не поступают.

В строке EXTENSION также бывает **NEEDS UPDATE** (нажмите **UPDATE**) — после обновления приложения, изменившего расширение, — и **UNINSTALL** (нажмите дважды для подтверждения; macOS может запросить пароль администратора). Удаление VPuppet.app из /Applications также удаляет расширение.

</Tab>
<Tab value="Windows">

Windows 10 или 11.

<Steps>
<Step>
В разделе **VIRTUAL CAM** нажмите **REGISTER CAMERA** и подтвердите запрос администратора. Это нужно сделать один раз.
</Step>
<Step>
Включите **CAMERA OUTPUT** (`W`).
</Step>
</Steps>

Камеру могут использовать только 64-битные программы.

</Tab>
<Tab value="Linux">

На Linux используется устройство v4l2loopback, которое вы создаёте один раз. Панель показывает команду; щёлкните по ней, чтобы скопировать:

```sh
sudo modprobe v4l2loopback devices=1 video_nr=10 card_label="VPuppet" exclusive_caps=1
```

Возможно, сначала придётся установить пакет v4l2loopback для вашего дистрибутива. Затем включите **CAMERA OUTPUT** (`W`). На Linux камера называется **VPuppet**.

</Tab>
</Tabs>

## Использование в программе

Выберите **VPuppet Virtual Camera** (на Linux — **VPuppet**) в качестве камеры:

- **Zoom:** Настройки → Видео → Камера.
- **Discord:** Настройки → Голос и видео → Камера.
- **Google Meet, FaceTime, OBS:** в списке выбора камеры / источника видео.

VPuppet продолжает отслеживать, отрисовывать и передавать изображение, даже когда его окно свёрнуто, скрыто или перекрыто.

## Нет встроенной камеры? Вариант через OBS [#obs-route]

Этот способ работает в любой ОС без установки драйвера камеры — например, с неподписанной сборкой для macOS.

<Steps>
<Step>
В VPuppet выберите фон. Зелёный **COLOUR** (`#00ff00`) проще всего вырезать.
</Step>
<Step>
Нажмите `H` для режима захвата: останется только аватар.
</Step>
<Step>
В OBS добавьте источник захвата окна и выберите окно VPUPPET: **macOS Screen Capture** (метод *Window Capture*) на macOS, **Window Capture** на Windows, **Window Capture (Xcomposite)** на Linux.
</Step>
<Step>
Для зелёного фона: правый щелчок по источнику → **Filters** → **+** → **Chroma Key** (цвет ключа — зелёный).
</Step>
<Step>
Нажмите **Start Virtual Camera** в OBS и выберите **OBS Virtual Camera** в программе видеосвязи.
</Step>
</Steps>

<Callout title="Захват с прозрачностью">
CLEAR делает окно прозрачным, но сохранит ли OBS эту прозрачность, зависит от ОС и способа захвата (на Linux к тому же нужен композитный менеджер). Хромакей — надёжный способ.
</Callout>
