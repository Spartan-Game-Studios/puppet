打开 **SCENE**（`B`）选择模型身后的内容。

## 背景

![场景窗口，使用“温馨小屋”环境](/screenshots/zh-CN/scene.webp)

**BACKGROUND** 区提供：

- **COLOUR**：纯色，含色键预设（绿色、蓝色、品红……）或任意自选颜色；
- **CLEAR**：透明窗口；
- **IMAGE**：你选择的图片（**PICK IMAGE**）；
- **3D**：带光照的 3D 环境（`E` 切换）。

<Callout title="摄像头没有 Alpha 通道">
虚拟摄像头无法传输透明度。选择 CLEAR 时，它会把模型叠加在所选颜色上发送（默认绿色），因此接收端仍可进行色键抠像。
</Callout>

## 3D 环境

![六个内置环境](/screenshots/environments.jpg)

按 `E`（或把背景切换为 3D），让模型站在有光照的场景中。六个内置场景由应用在运行时生成：

| 场景 | 内容 |
|---|---|
| STUDIO CYCLORAMA | 无缝摄影棚弧形背景，柔和的主光、补光和轮廓光，两个柔光箱框住画面 |
| COSY ROOM | 贴着墙纸的房间一角，有书架、黄昏时分的窗户、地毯，以及真正照亮模型的落地灯 |
| MOOR AT DUSK | 起伏的石楠荒原、一圈立石、低垂的太阳、雾气和飘动的薄雾 |
| NIGHT CLEARING | 星空下环绕的针叶林、月光和萤火虫 |
| NEON GRID | 滚动的合成器浪潮网格、条纹太阳、发光的山脊 |
| CONCRETE HALL | 木模清水混凝土、立柱、光槽、一扇条形窗和一条橙色线条 |
| CUSTOM | 你自己的 `.glb` / `.gltf` 场景和等距柱状投影 `.hdr` / `.exr` 天空 |

### 自定义场景

用 **SCENE** 加载 `.glb` 或 `.gltf`，用 **SKY** 加载天空，或把文件拖到窗口上。`.gltf` 可以引用同目录下的 `.bin` 和纹理文件。**NO SKY** 移除自定义天空。

- **位置：** SCALE（0.01–100×）、POS X / Y / Z 和 ROTATE。加载的场景会以模型为中心，最低点位于地面。
- **FLOOR M**（所有场景）上下移动场景，使其与模型的脚对齐。
- 自定义 HDR 天空也会照亮模型和场景。

应用会重新打开上次使用的自定义场景和天空。**RESET THIS SCENE** 恢复场景的外观和位置。

### 外观

- **光照：** SCENE 使用场景自带的光照；KEY、RIM 和 SOFT 改变其风格。**INTENSITY**（强度）和 **TEMP K**（白平衡；6500 为中性）叠加在其上。光照会保持在一定范围内，使面部既不过曝也不发黑。
- **氛围：** **FOG**（雾，0.5 为场景默认值）以及模型脚下的 **GROUND SHADOW**（地面阴影）。
- **镜头：** **IDLE SWAY** 增加约 ±1 cm 的缓慢漂移。**DEPTH OF FIELD**（景深，默认关闭，仅 HIGH 画质）让模型保持清晰并虚化背景。
- **画质：** **LOW** 使用柔和的圆形阴影，无后期处理。**HIGH** 增加真实的方向光阴影，并允许景深。

外观设置按场景分别保存。

<Callout type="warn" title="性能">
景深会明显降低追踪能达到的速度，因此默认关闭。如果在 3D 场景中追踪变慢，请先尝试 LOW 画质。
</Callout>

## 取景

![同一个虚拟形象的胸像、半身和全身取景](/screenshots/framing.webp)

舞台上的 **02 FRAMING** 可选择 **BUST**（半身）、**UPPER**（上半身）或 **FULL**（全身）。取景会根据模型大小缩放，因此非常小或非常大的模型也能得到合适的构图。

## 捕获视图

按 `H`（或顶栏中的 **CAPTURE VIEW**）隐藏全部界面，只留下模型，便于在 OBS 中干净地捕获窗口。`Esc` 退出捕获视图。

无论屏幕上是否显示，虚拟摄像头发送的始终是这个捕获视图。
