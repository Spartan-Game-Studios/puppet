VPuppet 模拟你的 VRM 已有的弹簧骨骼（头发、裙子、斗篷、丝带、耳朵……）。除了普通 VRM 导出已包含的内容外，模型无需任何额外设置。

## 布料解算器的作用

- **面片整体运动。** 自动找到相邻的骨骼链（围绕臀部的一圈裙摆、斗篷、刘海）并连接成网格，让面片作为一个整体摆动，而不是散成一缕一缕。
- **身体参与碰撞。** 根据骨架生成胶囊碰撞体，并贴合网格（臀部、腿、躯干、手臂、肩膀、颈部、头部），与模型自带的碰撞体一起使用。碰撞以整段计算，因此快速移动的手臂或腿不会在帧与帧之间穿过布料。
- **保留原有设置的含义。** 模型中的刚度、阻力和重力按建模者的设定生效。裙子和斗篷的刚度会向下摆逐渐减弱，使其自然垂坠。
- **保持稳定。** 模拟以固定频率运行，限制速度并平滑身体输入，因此追踪抖动时头发和布料不会乱甩。

## 快速切换

| 按键 | 设置 |
|---|---|
| `8` | **OFF**：无物理 |
| `9` | **STIFF**：少量运动 |
| `0` | **NORMAL** |
| `R` | 归位：将物理重置到静止状态 |

## PHYSICS 窗口（`P`）

![物理窗口：布料求解器、分组和碰撞体](/screenshots/zh-CN/physics.webp)

- **布料分组：** 连接开关、刚度，以及逐链的分组覆盖。
- **骨骼链：** 每条链的开关，以及刚度、阻力和重力倍数。
- **碰撞体：** 每个碰撞体的开关，包括生成的 **BODY** 碰撞体。
- **SETTLE** 重置模拟；**RESET OVERRIDES** 清除你对此模型的修改。
- **SOLVER → LEGACY** 切换到之前的解算器（three-vrm 的弹簧骨骼加稳定器）。它还支持 VRM 扩展碰撞体规范中的平面碰撞体和"内部"碰撞体，布料解算器会忽略这些。

覆盖设置按模型保存，因此同一个文件每次都会恢复你的设置。

## 局限

- 这是骨骼布料：两条相连骨骼链之间的网格仍由蒙皮弯曲，因此粗糙的绑定（链少、段长）无法细致地折叠。
- 非常宽松、蒙皮到身体而非弹簧骨骼上的衣服，会使生成的碰撞体比实际身体更胖。
- 在模型静止姿势中与身体重叠的部分会保持重叠。
- 扫过抬起手臂的头发或布料可能会挂在手臂上，直到手臂再次移动，就像真实的头发一样。
