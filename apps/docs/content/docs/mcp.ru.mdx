## Что это

VPuppet может запускать локальный сервер [MCP](https://modelcontextprotocol.io) (Model Context Protocol), чтобы ИИ-агенты на вашем компьютере (Claude Code, Claude Desktop, Cursor и другие MCP-клиенты) могли работать с запущенным приложением. Агент может:

- проверять модель на сцене, пока вы собираете её в Blender, включая покрытие perfect sync;
- делать снимки сцены;
- пробовать выражения и анимационные клипы;
- читать статистику трекинга, последние сообщения о состоянии и ошибки.

Это помогает собирать аватар с помощью агента и выяснять, почему что-то не работает.

## Включение

<Steps>
<Step>
Откройте окно **VMC** (`N`) и найдите раздел **AI AGENTS (MCP)** (ИИ-агенты).
</Step>
<Step>
Отметьте **ALLOW AI AGENTS (LOCAL MCP SERVER)** (разрешить ИИ-агентов, локальный MCP-сервер). По умолчанию эта опция выключена.

При первом включении VPuppet создаёт случайный токен доступа. **PORT** (порт) — `39540`, если вы не измените его там же.
</Step>
</Steps>

Сервер работает, только пока VPuppet открыт и эта опция включена.

## Регистрация ИИ-клиентов [#install]

Запустите установщик, когда VPuppet работает и опция включена. Он находит на компьютере Claude Code, Cursor и Claude Desktop и добавляет в каждый сервер `vpuppet`.

<Tabs items={['macOS / Linux', 'Windows']}>
<Tab value="macOS / Linux">

```sh
curl -fsSL https://raw.githubusercontent.com/Spartan-Game-Studios/puppet/main/apps/docs/public/mcp/install.sh | sh
```

Чтобы снова удалить записи:

```sh
curl -fsSL https://raw.githubusercontent.com/Spartan-Game-Studios/puppet/main/apps/docs/public/mcp/install.sh | sh -s -- --uninstall
```

</Tab>
<Tab value="Windows">

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/Spartan-Game-Studios/puppet/main/apps/docs/public/mcp/install.ps1 | iex
```

Чтобы снова удалить записи:

```powershell
$env:VPUPPET_MCP_UNINSTALL = 1; irm https://raw.githubusercontent.com/Spartan-Game-Studios/puppet/main/apps/docs/public/mcp/install.ps1 | iex
```

</Tab>
</Tabs>

Что делает установщик:

- читает токен из папки настроек VPuppet (и никогда его не выводит);
- **Claude Code:** выполняет `claude mcp add --transport http --scope user`;
- **Cursor:** добавляет сервер в `~/.cursor/mcp.json`;
- **Claude Desktop:** добавляет его в `claude_desktop_config.json` через мост [`mcp-remote`](https://www.npmjs.com/package/mcp-remote), которому нужен Node.js (`npx`);
- объединяет записи с существующими файлами настроек и предварительно делает их резервные копии. Запускать его повторно безопасно.

**Запустите его снова** после нажатия **NEW TOKEN** (новый токен) или смены порта, чтобы клиенты получили новые значения. Перезапустите клиент после того, как установщик изменил его настройки.

Параметры задаются переменными окружения:

| Переменная | Действие |
|---|---|
| `VPUPPET_CONFIG_DIR` | Папка настроек VPuppet, если она находится не в обычном месте |
| `VPUPPET_MCP_PORT` | Порт, если установщик не может его прочитать |
| `VPUPPET_MCP_CLIENTS` | Какие клиенты настраивать, например `"claude-code cursor"` (по умолчанию: `claude-code cursor claude-desktop`) |

<Callout title="Только Claude Code?">
Кнопка **COPY CLAUDE CODE COMMAND** в разделе AI AGENTS копирует готовую команду `claude mcp add` с текущим портом и токеном. Вставьте её в терминал.
</Callout>

## Другие клиенты

Подключиться может любой MCP-клиент с поддержкой Streamable HTTP:

- **URL:** `http://127.0.0.1:39540/mcp` (или заданный вами порт)
- **Заголовок:** `Authorization: Bearer <token>`, где токен — содержимое файла `mcp-token` в папке настроек VPuppet:
  - macOS: `~/Library/Application Support/com.spartangamestudios.vpuppet/`
  - Windows: `%APPDATA%\com.spartangamestudios.vpuppet\`
  - Linux: `~/.config/com.spartangamestudios.vpuppet/`

## Инструменты

| Инструмент | Что делает |
|---|---|
| `app_status` | Сводка о приложении: версия, состояние демоверсии, модель на сцене, открыт ли HOME, режим и состояние трекинга, выходы и частота кадров. Агенты вызывают его первым. |
| `library_list` | Список моделей в библиотеке со статистикой, предупреждениями проверки моделей и значком лицензии. |
| `library_load` | Загружает модель из библиотеки на сцену. |
| `library_import` | Импортирует файл `.vrm` по пути в библиотеку (миниатюра, проверки) и при желании загружает его. |
| `model_inspect` | Всё о модели на сцене: версия VRM и метаданные, назначенные и недостающие гуманоидные кости, все выражения, покрытие ARKit perfect sync (включая имена, записанные иначе), пресеты, look-at, цепочки spring bones и коллайдеры, статистика мешей / материалов / текстур, лицензия, предупреждения проверки моделей. |
| `stage_screenshot` | PNG сцены в том виде, в каком вы её видите, или аватар спереди в кадре face / bust / upper / full — без смещения вашей камеры. |
| `expression_set` | Удерживает выражение с заданным весом поверх трекинга или сбрасывает удерживаемые выражения. |
| `expression_sweep` | Включает каждое выражение по очереди при замороженной позе и сообщает о формах, которые ничего не делают, и о перепутанных левых / правых формах; прилагает обзорный лист. |
| `clip_list` | Список встроенных и импортированных анимационных клипов. |
| `clip_play` | Запускает или останавливает клип на аватаре. |
| `tracking_stats` | Состояние трекинга: режим, статус, частота кадров, задержка и время инференса по каждому конвейеру, поиск рук по сторонам, текущие жесты. |
| `logs_recent` | Последние строки состояния, предупреждения и ошибки. |
| `settings_get` | Читает настройки, которые агенту разрешено менять. |
| `settings_set` | Меняет режим трекинга, сглаживание, кадрирование, фон или режим физики — сразу. |

## Типичный рабочий цикл [#workflow]

Сборка или исправление аватара с агентом обычно идёт по такому кругу:

<Steps>
<Step>
**Проверка.** Агент запускает `model_inspect` для модели на сцене: недостающие кости, выражения, которые ничего не делают, каких имён ARKit не хватает для perfect sync.
</Step>
<Step>
**Исправление в Blender** (или в программе, в которой вы делали модель), затем повторный экспорт `.vrm`.
</Step>
<Step>
**Повторный импорт.** Агент запускает `library_import` с новым файлом. Заново экспортированный файл становится новой записью в библиотеке.
</Step>
<Step>
**Проверка результата.** Агент запускает `expression_sweep` по набору ARKit, чтобы убедиться, что каждая форма perfect sync двигает лицо и с правильной стороны.
</Step>
</Steps>

## Безопасность

- **Только локально.** Сервер слушает только `127.0.0.1`, поэтому другие компьютеры не могут к нему подключиться. Запросы с заголовком `Origin` от браузера или с именем хоста, отличным от этого компьютера, отклоняются, так что веб-страницы тоже не могут до него достучаться.
- **Токен.** Каждому запросу нужен токен. Он случайный, создаётся при первом включении сервера и хранится как `mcp-token` в папке настроек VPuppet (на macOS и Linux его можете прочитать только вы). Обращайтесь с ним как с паролем. **NEW TOKEN** заменяет его; после этого снова запустите установщик.
- **Что может менять агент.** Агент может загружать и импортировать модели и менять безопасный набор настроек: режим трекинга, сглаживание, кадрирование, фон и режим физики. Настройки VMC, виртуальной камеры и MCP он менять **не может**. Он читает только те файлы, которые вы или агент указали для импорта.
- **Демоверсия.** Когда 100 часов демоверсии израсходованы, загрузка моделей через MCP отклоняется — так же, как в самом приложении.
- Агент действует с теми правами, которые вы дали ему в своём клиенте. Проверяйте, что он предлагает, прежде чем одобрять.
