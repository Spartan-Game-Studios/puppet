---
title: 口型同步
description: 在摄像头看不到嘴时用麦克风驱动嘴部，或与追踪一起使用。
---

打开 **LIP SYNC**（`S`）。口型同步默认关闭；只有在你选择模式时，VPuppet 才会请求麦克风权限。

## 模式

![口型同步窗口：模式、麦克风、门限、增益和口型等级](/screenshots/zh-CN/lipsync.webp)

| 模式 | 由什么驱动嘴部 |
|---|---|
| **OFF** | 仅面部追踪。 |
| **FALLBACK** | 仅在面部未被追踪时使用你的声音（平滑过渡）。 |
| **BLEND** | 逐个嘴型取追踪和声音中较大的值。 |
| **AUDIO** | 仅使用你的声音。 |

## 设置

- 选择**麦克风**。
- **GATE DB** 设置门限，低于该电平的声音会被忽略。如果背景噪音让嘴动起来，请调高。
- 电平表显示输入电平、门限以及检测到的每个嘴型。

VPuppet 将你的声音与五个元音进行匹配。预设模型使用 `aa` `ih` `ou` `ee` `oh`；perfect sync 模型使用 `jawOpen`、`mouthFunnel`、`mouthPucker` 和 `mouthStretch`。嘴张开得很快（30 ms），闭合稍慢（90 ms）。

<Callout title="FALLBACK 与较弱的追踪">
FALLBACK 只在面部丢失时切换。它无法判断嘴部追踪只是变弱了；这种情况请使用 BLEND。
</Callout>
